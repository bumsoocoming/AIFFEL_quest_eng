# 🏠 회귀 — 자동 주택 가치 평가(AVM) 분석 정리

> 작성자: 김범수
> 날짜: 2026-06-17
> 데이터셋: California Housing (20,640 구역, 8 피처)
> 목표: 주택 가치(MedHouseVal)를 예측하고, **무엇이 가격을 움직이는가**를 해석

---

## 1. 모델 성능 — 베이스라인을 이기는 여정

| 모델 | MAE | RMSE | MAPE | 베이스라인 대비 개선 |
|------|-----|------|------|------|
| 베이스라인(평균) | 0.906 | 1.145 | 62.9% | — |
| 선형회귀(기본) | 0.533 | 0.746 | 32.0% | 41.2% ↓ |
| 선형+FE+log | 0.478 | 0.745 | 26.6% | 47.2% ↓ |
| Ridge+FE+log | 0.478 | 0.745 | 26.7% | 47.2% ↓ |
| **스플라인+Ridge** | **0.421** | **0.610** | **23.4%** | **53.5% ↓** 🏆 |

- 단위: 타깃이 $100,000 단위이므로 MAE 0.421 ≈ **±$42.1k** 오차.
- 핵심 원칙: **"베이스라인(평균)을 못 이기면 모델은 의미가 없다."** 최종 모델은 평균 대비 **MAE를 절반 이하로** 줄였다.
- 피처 엔지니어링(파생변수 + log 타깃)과 **비선형(스플라인)** 허용이 성능을 끌어올린 두 축이다.

## 2. 무엇이 집값을 움직이는가 (계수 해석)

설명용 선형 모델의 주요 계수:

```
MedInc (중위소득)     +0.757   💰 압도적 1위 — 소득이 집값의 핵심 동인
Latitude (위도)       -0.910   북쪽일수록 ↓ (남부 캘리포니아가 비쌈)
Longitude (경도)      -0.843   서쪽(해안)일수록 ↑
rooms_per_person      +0.411   1인당 방 수 많을수록 ↑
bedroom_ratio         +0.281
```

→ **소득 + 위치(해안·남부)** 가 캘리포니아 집값을 지배한다.

### ⚠️ 다중공선성(VIF) 주의
```
AveRooms          VIF 23.9   ← 매우 높음 (방 수 ↔ 침실 수가 얽힘)
rooms_per_person  VIF 15.0
bedroom_ratio     VIF 10.2
```
VIF가 높은 변수는 계수의 **부호·크기 해석을 신뢰하기 어렵다.** Ridge/Lasso 같은 정규화로 안정화하고, Lasso는 `AveRooms`, `Population`을 0으로 버렸다.

## 3. 변수 영향력 분석 (Part 6)

- **Permutation Importance**: 변수를 섞었을 때 성능이 얼마나 나빠지는지로 중요도 측정.
- **PDP (부분 의존도)**: 한 변수만 쓸어보며 평균적인 효과 곡선 확인.
- **ICE**: 평균(PDP)에 가려진 개체별 차이 확인.
- **SHAP**: "이 한 채는 왜 이 값으로 예측됐나"를 개별 설명 → MedInc가 대체로 가장 큰 기여.

핵심: **소득(MedInc)** 이 전역적으로도, 개별 예측에서도 가장 강력한 변수다.

---

## 4. 비선형 — 회귀를 벗어나지 않고 곡선 잡기 (Part 7)

```
선형(직선 가정)     CV MAE 0.475
스플라인(곡선 허용)  CV MAE 0.415  ← 개선
```
`SplineTransformer`로 변수에 곡선 효과를 허용하자 성능이 올랐다. 선형회귀의 해석력을 유지하면서 비선형 패턴을 잡는 절충안.

---

## 5. 예측 신뢰도 — 점 예측에 ±범위 붙이기 (Part 8)

```
90% 예측구간 실제 coverage: 90.3%  (목표 90% 정확 달성)
평균 구간 폭: ±$97.6k
```
`QuantileRegressor`로 상·하한을 예측 → "이 집은 $300k ± $97.6k"처럼 **범위로 답하면** 단일 점 예측보다 정직하고 신뢰성 있다.

---

## 6. 에러 분석 — 어디서 틀리는가 (Part 9)

절대오차 상위 매물:
```
실제 5.00 → 예측 0.72  (저소득 지역인데 실제론 최고가)
실제 5.00 → 예측 1.18
실제 0.68 → 예측 4.33  (고소득인데 실제론 저가)
```

→ 실제값 **5.00 = $500k는 데이터의 "숨은 상한선(cap)"**. 진짜 비싼 집이 전부 5.0으로 잘려서, 모델이 그 위를 예측할 수 없다. **데이터의 한계**이지 모델 결함이 아니다. (Part 0에서 미리 이 cap을 발견한 것이 주효)

---

## 🎓 이 노트북에서 가져갈 실무 원칙

```
1. 모델보다 데이터를 먼저 의심하라 — 타깃의 숨은 상한선(cap) 발견
2. 베이스라인을 못 이기면 모델은 의미가 없다
3. 데이터 누수(leakage)를 막아야 점수가 정직하다
4. 계수 해석에는 다중공선성(VIF) 함정이 있다 — 정규화로 안정화
5. 점 예측보다 ±예측구간이 정직하다
6. 비선형은 회귀를 벗어나지 않고도(스플라인) 잡을 수 있다
7. 에러 분석은 다음 개선의 지도다
```

**한 줄 요약:** 캘리포니아 집값은 **소득과 위치(해안·남부)** 가 지배하며, 좋은 회귀 모델은 *예측 정확도*뿐 아니라 *해석 가능성*과 *예측 신뢰구간*까지 갖춰야 한다.
