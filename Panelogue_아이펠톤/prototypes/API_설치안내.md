# 회의 프로그램 설치 안내

프로그래밍 몰라도 됩니다. **순서대로 3단계만** 하시면 됩니다.
막히면 어느 단계에서 무슨 글자가 떴는지 캡처해서 보내주세요.

---

## 0. 받은 것 확인

압축을 풀면 폴더 안에 이런 게 들어있습니다.

```
setup.bat / setup.sh    ← 처음 한 번만 실행 (설치)
run.bat   / run.sh      ← 회의 돌릴 때마다 실행
personas.yaml           ← 등장인물 설정 (여기만 고치면 됨)
meeting.py              ← 프로그램 본체 (건드리지 마세요)
```

**압축은 반드시 푼 다음에 실행하세요.** 압축 파일 안에서 바로 더블클릭하면 실패합니다.
바탕화면이나 문서 폴더처럼 **한글·띄어쓰기 없는 경로**에 두는 게 안전합니다.

---

## 1. 파이썬 설치 (이미 있으면 건너뛰기)

### 윈도우

1. https://www.python.org/downloads/ 접속 → 노란 **Download Python** 버튼
2. 받은 파일 실행
3. **설치 첫 화면 맨 아래 `Add python.exe to PATH` 체크박스를 반드시 켜세요.**
   이거 안 켜면 나중에 "파이썬이 없습니다"가 뜹니다. 가장 많이 하는 실수입니다.
4. `Install Now` 클릭

### 맥

터미널(스팟라이트에서 `터미널` 검색)을 열고 붙여넣기:

```bash
python3 --version
```

버전 숫자가 나오면 이미 있는 겁니다. 없다고 나오면:

```bash
brew install python3
```

---

## 2. 설치 실행 (처음 한 번만)

### 윈도우

폴더 안의 **`setup.bat` 더블클릭**

- "Windows의 PC 보호" 파란 창이 뜨면 → **추가 정보** → **실행**
- 1~2분 기다리면 메모장이 저절로 열립니다
- **전달받은 키를 `sk-or-v1-` 자리에 통째로 붙여넣고 저장(Ctrl+S) 후 닫기**

`.env` 파일 내용은 이렇게 생겨야 합니다. 따옴표나 띄어쓰기 넣지 마세요.

```
OPENROUTER_API_KEY=sk-or-v1-abc123...
```

### 맥

터미널을 열고, 폴더를 터미널 창에 **드래그해서** 경로를 넣습니다:

```bash
cd [여기에 폴더를 드래그]
bash setup.sh
```

편집기가 열리면 키를 붙여넣고 `Ctrl+O` → `Enter` → `Ctrl+X`로 저장·종료.

---

## 3. 실행

### 윈도우
**`run.bat` 더블클릭** → 번호 입력 → 엔터

### 맥
```bash
./run.sh
```

메뉴가 뜹니다.

```
1. 연습 실행  (돈 안 씀, 흐름만 확인)
2. 1분 회의   (약 8턴)
3. 3분 회의   (약 20턴)
4. 5분 회의   (약 35턴)
```

**처음에는 반드시 1번을 먼저 돌려보세요.** 돈이 안 나가고 설치가 제대로 됐는지만 확인합니다.
1번이 잘 돌아가면 2번부터 실제 회의입니다.

끝나면 폴더 안 `logs` 폴더에 두 개가 생깁니다.

- `meeting_날짜.md` — 사람이 읽는 대화록 (이걸 공유하시면 됩니다)
- `meeting_날짜.json` — 모델·토큰·비용까지 들어간 원본

---

## 4. 등장인물 바꾸기

`personas.yaml`을 메모장이나 텍스트 편집기로 엽니다.

```yaml
topic: "여기에 회의 주제를 씁니다"

  - name: "축구선수"
    model: "x-ai/grok-4.6"
    persona: |
      프로 축구 선수 출신. 몸으로 배운 것만 믿는다.
      - 이론이 길어지면 끊고 "직접 해봤냐"고 묻는다.
      - 직설적이고 짧다. 3문장 이내.
```

**주의할 점**

- **들여쓰기(칸 띄우기)를 건드리면 프로그램이 안 돌아갑니다.** 글자만 바꾸세요.
- 탭 키 말고 **스페이스바**로만 띄우세요.
- `persona`는 형용사("활발한, 긍정적인")로 쓰면 잘 안 먹힙니다.
  **행동 규칙**으로 쓰세요 — 무엇을 하고, 무엇을 안 하고, 몇 문장으로 말하는지.

---

## 5. 키 취급 규칙

받으신 키는 **회사 돈이 나가는 열쇠**입니다.

- 카톡·메일·슬랙에 **키를 그대로 붙여넣지 마세요**
- 깃허브에 폴더째 올리지 마세요 (`.env`는 자동으로 제외되게 해뒀지만, 확인하세요)
- 다른 사람에게 전달하지 마세요. 필요하면 관리자에게 별도 키를 요청하세요
- **키가 유출된 것 같으면 즉시 관리자에게 알리세요.** 삭제하면 바로 막힙니다

키마다 사용 한도가 걸려 있어서, 한도를 넘으면 그 키만 멈춥니다.
"잔액 부족" 메시지가 뜨면 관리자에게 말씀하세요.

## 6. 잘 안 될 때

| 화면에 뜨는 말 | 해결 |
|---|---|
| `파이썬이 없습니다` | 파이썬 설치할 때 `Add python.exe to PATH` 체크를 빠뜨린 것. 재설치하면서 체크 |
| `OPENROUTER_API_KEY 가 없습니다` | `.env` 파일이 없거나 키가 안 들어감. 메모장으로 열어서 확인 |
| `401` 또는 `No auth credentials` | 키 앞뒤에 공백이나 따옴표가 붙음. 지우고 다시 저장 |
| `402` 또는 `Insufficient credits` | 이 키의 사용 한도 소진. 관리자에게 요청 |
| `404` 또는 `model not found` | `personas.yaml`의 모델 이름 오타 |
| 한글이 `?????`로 깨짐 | 윈도우 구버전. `run.bat` 대신 PowerShell에서 실행해보세요 |
| 설치 중 멈춤 | 회사 방화벽. 개인 네트워크나 핫스팟으로 재시도 |
| 창이 뜨자마자 사라짐 | 압축을 안 풀고 실행한 경우. 폴더째 압축 해제 후 다시 |
