# 샘플 실행

`2026-08-19`에 Gemini 3.6 Flash로 돌린 단일 조건 결과다. 모든 부서 메모를 한 모델이 읽고 쓴 대책이라, 멀티 토론 로그가 아니다.

- 유형: 일부 보존·우회 개발 (`PARTIAL`)
- 공사 중지, 정밀조사 10개월, 지연 10개월
- 발굴비는 시행자 부담
- 자동 채점 100점. 비밀 정보(12개월 위약, 초등 교육, 인접 녹지)를 반영했다.

원본은 `outputs/20260819_110029_single_demo2/`.
멀티 조건은 같은 날 무료 할당량에 걸려 완성본이 없다. 키가 살아 있으면 `py -3.12 run.py --provider gemini --mode multi`로 이어서 돌리면 된다.
