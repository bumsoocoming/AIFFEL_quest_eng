# 멀티 페르소나 회의 — OpenRouter 셋업 & 실행

키 하나로 OpenAI · Anthropic · Google · xAI 모델을 섞어 쓰는 구조입니다.

---

## 1. OpenRouter 결제 절차

### 가입 · 키 발급

1. `openrouter.ai` 접속 → 우상단 **Sign in** (구글/깃허브 계정으로 바로 가입됨)
2. 우상단 프로필 → **Keys** → **Create Key**
3. 이름 아무거나 (예: `meeting-app`) 입력 → 생성
4. **`sk-or-v1-...` 문자열이 이 화면에서만 보입니다.** 창을 닫으면 다시 못 봅니다. 바로 복사하세요.
5. 키 생성 시 **Credit limit**을 걸 수 있습니다. 예: `10` → 이 키로 최대 $10까지만 쓰이고 멈춤. 실수로 무한 루프 돌 때 이게 안전장치가 됩니다. 반드시 걸어두세요.

### 크레딧 충전

1. 프로필 → **Credits** (`openrouter.ai/settings/credits`)
2. **Add Credits** → 금액 입력
3. 결제 수단: **해외결제 되는 신용/체크카드**, **AliPay**, **USDC(암호화폐)**
   - 국내 전용 카드는 안 됩니다. 비자/마스터 해외결제 열려 있어야 합니다.
   - 카카오뱅크·토스 체크카드도 해외결제 활성화하면 대부분 됩니다.

### 알아둘 조건

| 항목 | 내용 |
|---|---|
| 충전 수수료 | 카드 **5.5%** (최소 $0.80) / 암호화폐 **5%** |
| 토큰 단가 | 마크업 **없음**. 각 회사 직접 결제와 동일 |
| 크레딧 유효기간 | 구매 후 **1년** |
| 무료 모델 한도 | 크레딧 0원이면 하루 50회 / **$10 이상 충전 시 하루 1,000회** |
| 자동 충전 | Auto Top-Up 켜면 잔액이 기준 아래로 떨어질 때 자동 결제 |

**수수료 계산**: $10 넣으면 카드에서 $10.55가 빠지고 잔액은 $10입니다.
최소 금액을 여러 번 넣으면 $0.80 최소 수수료 때문에 손해입니다.
$14.55 미만을 충전하면 5.5%보다 $0.80 쪽이 커집니다 — **첫 충전은 $10~20 사이가 무난합니다.**

### 프라이버시 설정 (한 번은 보고 가세요)

Settings → Privacy 에서 프롬프트 로깅 여부를 정합니다.
로깅에 동의하면 1% 할인이 붙지만, 회의 내용에 민감한 게 들어간다면 꺼두세요.
제공사별 로깅 정책도 여기서 개별로 막을 수 있습니다.

## 2. 설치

```bash
pip install openai pyyaml python-dotenv
```

같은 폴더에 `.env` 파일을 만들고 한 줄:

```
OPENROUTER_API_KEY=sk-or-v1-여기에붙여넣기
```

> `.env`는 절대 깃허브에 올리지 마세요. `.gitignore`에 `.env` 추가하세요.

---

## 3. 실행

```bash
python meeting.py --dry-run --turns 4    # 돈 안 쓰고 흐름만 확인 (여기부터 하세요)
python meeting.py --length 1min          # 실제 실행, 8턴
python meeting.py --length 3min          # 20턴
python meeting.py --length 5min          # 35턴
python meeting.py --turns 12             # 턴 수 직접 지정
```

끝나면 `logs/` 안에 두 개가 생깁니다.

- `meeting_날짜.json` — 발언별 모델·토큰·비용까지 들어간 원본
- `meeting_날짜.md` — 사람이 읽거나 공유할 대화록

## 4. 페르소나 고치기

`personas.yaml`만 건드리면 됩니다. **모델보다 `persona` 문장이 결과를 훨씬 많이 좌우합니다.**

```yaml
  - name: "축구선수"
    model: "x-ai/grok-4.6"
    persona: |
      프로 축구 선수 출신. 몸으로 배운 것만 믿는다.
      - 이론이 길어지면 끊고 "직접 해봤냐"고 묻는다.
      - 직설적이고 짧다. 3문장 이내.
```

성격을 형용사로 쓰면("활발한, 긍정적인") 잘 안 먹힙니다.
**행동 규칙으로 쓰세요** — 무엇을 하고, 무엇을 안 하고, 몇 문장으로 말하는지.

모델 슬러그는 `openrouter.ai/models` 에서 확인해 바꾸면 됩니다.
`~openai/gpt-latest` 처럼 `~`가 붙은 별칭을 쓰면 항상 최신 플래그십으로 자동 연결됩니다.

## 5. 비용 감각

매 턴마다 이전 대화를 다시 보내기 때문에 **입력 토큰이 턴 수의 제곱으로 늘어납니다.**
35턴은 8턴의 4배가 아니라 15배쯤 나옵니다.

그래서 이 스크립트는 최근 8턴만 원문으로 보내고 그 이전은 요약으로 압축합니다
(`personas.yaml`의 `recent_turns`). 이 값을 키우면 맥락은 좋아지고 비용은 급하게 오릅니다.

실제 과금액은 매 호출마다 OpenRouter가 응답에 실어주므로 로그의 `total_cost_usd`가 정확합니다.
**추정하지 말고 1min 한 번 돌려서 찍힌 숫자로 계산하세요.**

## 6. 자주 막히는 지점

| 증상 | 원인 |
|---|---|
| `401 No auth credentials` | `.env` 위치가 실행 폴더와 다름. 또는 키 앞뒤 공백 |
| `402 Insufficient credits` | 잔액 부족, 또는 키에 걸어둔 Credit limit 소진 |
| `404 model not found` | 슬러그 오타. `openrouter.ai/models`에서 복사해 붙이세요 |
| 카드 결제 거부 | 해외결제 차단. 카드사 앱에서 해외결제 활성화 |
| 다들 비슷한 소리만 함 | 모델 문제가 아니라 persona가 두루뭉술한 것. 반대 입장을 명시적으로 넣으세요 |
