# verification — 수치 검증

발표자료와 대본에 인쇄된 **모든 수치를 원자료에서 다시 계산해 대조**하는 스크립트입니다.
숫자를 손으로 옮겨 적다 생긴 오류를 잡으려고 만들었고, 실제로 여러 건을 잡았습니다.

## 실행

```bash
python verify_deck.py     # 슬라이드 62개 항목
python verify_script.py   # 발표 대본 49개 항목
```

두 스크립트 모두 `Panelogue_발표자료.pptx` 와 아래 자료를 같은 작업 폴더에서 찾습니다.

```
merged/stance-events-merged.csv          → analysis/merged_185건/
pkg/Panelogue_턴별_입장변화_분석패키지/    → analysis/turn-dynamics_머스크·VAR/
mypkg/Panelogue_턴별_입장변화_분석패키지/  → analysis/turn-dynamics_사회자없는3주제/
charts.py                                 → presentation/src/
```

경로가 저장소 구조와 다르므로, 그대로 돌리려면 스크립트 상단 경로를 고치거나
위 대응대로 심볼릭 링크를 만들어야 합니다.

## K4가 왜 있나

초안에는 이런 표현이 있었고, 검증에서 걸러냈습니다.

| 걸러낸 표현 | 왜 문제였나 |
|---|---|
| "전부 로그 원문 그대로" | 실제로는 앞뒤를 자른 발췌 |
| "보시다시피 전부 미달성" | 표기가 미달성 / 2:2 분할 / 0/5 세 가지 |
| "나머지 세 명은 거의 평평" | 동네 통장은 80점 움직였음 |
| "실제로 효과가 보고됐" | 논문은 "일부 조건에서" 라고 씀 |
| "반박 태그는 85%" | 적용 범위 없이 반올림값만 제시 |
| "인과관계" | 탐색적 사례 연구인데 인과를 단정 |
